## Данные

Использован [Amazon Review Data (2018), Digital Music, 5-core](https://nijianmo.github.io/amazon/index.html). [Архив отзывов](https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/categoryFilesSmall/Digital_Music_5.json.gz) содержит оценки, ID пользователей и товаров, время и текст отзывов. После удаления дублей осталось **145 292** взаимодействия, **16 566** пользователей и **11 797** товаров. Данные не использовались на семинарах курса.

Релевантным считается будущий отзыв с оценкой не ниже 4. Отзыв не равен прослушиванию или покупке; это ограничение учитывается при интерпретации результатов.

## Эксперимент

Пять методов реализованы самостоятельно в отдельных файлах [`models/`](models/): item-kNN, implicit ALS, EASE, факторизационная машина с историческими признаками и ALS с таргетом, зависящим от оценки и давности отзыва.

Разбиение по времени: train — до **16.06.2016**, validation — до **02.02.2017**, затем test. Параметры выбраны по validation; для test модели переобучены на train+validation. Все сравниваются на одних пользователях и полном каталоге доступных объектов. Ранее оценённые товары исключаются, холодный старт учитывается отдельно. Метрики — **NDCG@10** (основная) и **Recall@10**.

| Модель | NDCG@10 | Recall@10 |
|---|---:|---:|
| Item-kNN | 0,01768 | 0,02696 |
| iALS | 0,01901 | 0,02809 |
| EASE | **0,01992** | **0,02902** |
| FM с историческими признаками | 0,01269 | 0,01755 |
| iALS с новым таргетом | 0,01887 | 0,02868 |

Среди пяти основных методов лидирует EASE. Исторические признаки улучшили FM относительно варианта только с ID; для нового таргета уверенного выигрыша относительно бинарного iALS не получено. Подробные таблицы, графики, контрольные эксперименты и ограничения приведены в [`experiments.ipynb`](experiments.ipynb) и [`results/conclusions.md`](results/conclusions.md).

## Запуск

Проверено на Linux, Python 3.12.3 и CPU. Из корня репозитория:

```bash
cd hw1
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export PYTHONHASHSEED=42
python -m nbconvert --to notebook --execute --inplace experiments.ipynb --ExecutePreprocessor.timeout=-1
```

Ноутбук сам получает и проверяет архив. Данные хранятся в `.local/data`; другой каталог задаётся через `RECSYS_DATA_DIR`. Если загрузка из текущей сети не проходит, поместите `Digital_Music_5.json.gz` в этот каталог: загрузчик проверит SHA-256 `703f60f74bf1967a75cbb3033532172eeb21139d4df04ec5fe44a7eb8d7fde58`. В первой кодовой ячейке `RECOMPUTE_ALL = True` принудительно пересчитывает модели; без локального кеша они обучаются автоматически. Полный прогон без кеша занял около 50 минут и до 2,4 GiB памяти рабочего процесса.

Код моделей и протокола — в `models/` и `utils/`, настройки — в [`configs/experiment.json`](configs/experiment.json), агрегированные результаты — в [`results/`](results/). Данные, веса и кеши исключены из Git. Проверки запускаются командой `python -m unittest discover -s tests` (175 тестов).
